# Text Classifier: Detection of Panic and Misinformation

Профессиональный инструмент для автоматического анализа текстовых данных в интересах OSINT (разведки на основе открытых источников). Модель предназначена для экспресс-фильтрации входящих потоков сообщений (из Telegram-каналов, чат-ботов или соцсетей) и классификации их на конструктивные сводки/новости и деструктивные панические настроения/ИПСО.

## 🚀 Архитектура и технические особенности

В проекте реализован классический паттерн **Feature Extraction** на базе глубокого трансформера, адаптированный под задачи быстрого инференса на ограниченных вычислительных мощностях:

1. **Backbone (Мультиязычный каркас):** Используется предобученная модель `bert-base-multilingual-cased`, которая «из коробки» эффективно обрабатывает кириллические тексты (русский, украинский языки) без необходимости предварительного перевода.
2. **Заморозка весов (Frozen Weights):** Все слои базового трансформера полностью заморожены (`requires_grad=False`). Градиенты рассчитываются исключительно для кастомного классификатора, что защищает модель от катастрофического забывания (catastrophic forgetting), снижает требования к видеопамяти (VRAM) и кратно ускоряет шаг обучения.
3. **Кастомный Mean Pooling с маскированием:** Агрегация смысла предложения реализована через усреднение векторов скрытых состояний (`last_hidden_state`). В отличие от базовых подходов, алгоритм учитывает `attention_mask`, динамически отсекая токены паддинга, чтобы нули не искажали семантическое представление батча.
4. **Стабильность вычислений:** Применение `torch.clamp(..., min=1e-9)` гарантирует защиту пайплайна от критической ошибки деления на ноль при случайном попадании пустых строк или некорректно токенизированного шума.
5. **Стратификация данных:** Разбиение выборки на обучающую и валидационную (`train_test_split`) производится с учетом пропорций классов, что нивелирует риски смещения модели при естественном дисбалансе собираемых из сети данных.

## 📊 Метрики качества

Для корректной оценки работы системы на этапе валидации рассчитываются две ключевые метрики:
*   **Accuracy** — общая доля правильных предсказаний.
*   **Weighted F1-Score** — сбалансированная метрика (гармоническое среднее между точностью и полнотой), которая является приоритетной в реальных задачах NLP из-за неизбежного перекоса данных в сторону обычных новостей.

## 📦 Структура входных данных

Модель считывает данные из файлов формата `.csv` с кодировкой `utf-8`. Таблица должна содержать две обязательные колонки:
*   `text`: Сырой текст сообщения (поста).
*   `label`: Целочисленная метка класса:
    *   `1` — **Сводка / Новости** (Конструктивная информация, сухие факты).
    *   `0` — **Фейк / Паника / ИПСО** (Эмоциональная дестабилизация, дезинформация).

## 📈 Перспективы масштабирования
*   Переход к полноценному Fine-Tuning (разморозке верхних слоев трансформера) при увеличении датасета свыше 10 000 постов для более тонкого улавливания военной терминологии.
*   Расширение структуры до 3 классов с разделением «Фейков» (псевдо-документальная ложь) и «Паники» (эмоциональный взрыв) в отдельные категории.
